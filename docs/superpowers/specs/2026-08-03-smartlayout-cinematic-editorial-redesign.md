# SmartLayout Cinematic Editorial Redesign

## Goal

重做《双峰：回归》smartLayout 示例，使它首先是一份高完成度的电影主题演示文稿，其次才承担四种 smartLayout 的能力验证。最终产物必须摆脱产品功能演示、右侧贴图卡和大面积无信息留白，呈现高密度但有秩序的电影杂志编辑感。

## Scope

- 新建一份 8 页演示文稿，不覆盖或删除现有版本。
- 使用当前 XSD 已公开的四种 `layoutType`：`solid-pyramid`、`step-pyramid`、`filled-up-step`、`linear-up-step`。
- 每种 smartLayout 至少真实渲染一次。
- 增加人物分身关系和时间闭环两类非 smartLayout 结构，证明 Skill 能正确降级。
- 使用影片素材、文字层级、遮罩和关系结构完成视觉，不新增运行时 planner 或几何引擎。

## Visual Direction

采用“电影杂志式高密度”而不是“极简留白”或“产品说明页”。

每页应同时存在三到四个信息层级：

1. 全幅或大比例影片画面，承担氛围和空间深度。
2. 一句明确的编辑观点，使用大号米白或暗红文字。
3. smartLayout 或自定义关系图，承担主要信息结构。
4. 2–4 个短旁注、引文、章节编号或微型标签，增加细读价值。

页面可以留白，但留白必须由暗部画面、人物视线或结构方向形成张力，不能是没有内容的纯色空区。

## Visual System

### Color

- 墨蓝黑 `rgba(7,18,29,1)`：主要暗部和遮罩。
- 深棕黑 `rgba(23,14,12,1)`：次级暗页。
- 米白 `rgba(235,218,186,1)`：标题和主要正文。
- 双峰红 `rgba(174,45,50,1)`：节点、关键层级和结论。
- 辅助灰蓝与褐色只用于 smartLayout 的同色系渐变，不出现彩虹配色。

### Typography

- 中文标题 30–42 pt，1–2 行；强调词可使用更大字号。
- 页面观点 15–20 pt；旁注 10–12 pt。
- smartLayout cell 使用 11–14 pt、2–8 个汉字的短标题。
- 删除所有面向实现者的字段说明，例如 `layoutType=`、`smartLayout field test`、验证备注和协议解释。

### Images

- 封面和结尾使用全幅画面。
- 内容页的影片画面至少占页面 45%，优先全幅铺底或大幅裁切，不使用独立白底“图片卡”。
- 使用遮罩保证文字对比，但遮罩应形成画面深度，不形成生硬的左右模板分栏。
- 同一素材不跨页重复使用。

### Composition

- smartLayout 是画面中的结构层，不是孤立的组件展示区。
- smartLayout 可落在暗部、人物视线留出的空间或画面下三分之一，但不得遮挡人物关键面部。
- 同一 deck 中至少使用四种明显不同的构图：全幅封面、左右张力、上下叠层、局部放大、关系网络。
- 不使用右图左组件的统一模板，不在每页重复相同的英文眉题和页脚。

## Page Design

### 1. 封面：梦境重新开启

- 全幅官方海报或 Cooper 主视觉。
- 标题与人物面部形成错位叠压，保留一句核心判断。
- 不出现 smartLayout。

### 2. 十八小时结构：一部被切开的电影

- 大幅横向剧照或海报裁切。
- 用章节编号、18 小时、三个观看阶段组成高密度编辑页。
- 不使用 smartLayout，为后续结构页建立叙事背景。

### 3. 现实层级：从日常走向不可解释

- 使用 `solid-pyramid`，4 层。
- 金字塔与人物海报产生前后景关系；层级标题保持短句。
- 旁边增加两条解释现实层如何逐层失效的微型注释。

### 4. Cooper 分身：身份并非并列，而是逐级失真

- 使用 `step-pyramid`，4 层。
- 四层分别表达特工身份、替身、Dougie、回归后的残缺主体。
- 结合人物大幅裁切和身份标签，形成密集但统一的阅读路径。

### 5. 悬疑升级：调查越深，现实越薄

- 使用 `filled-up-step`，5 个短标题。
- 阶梯叠在红房或夜景暗部，色阶从灰蓝逐步转红。
- 增加三处短旁注，分别解释空间、身份和时间如何同时失真。

### 6. 时间闭环：回到起点并不意味着回到原处

- 不使用 smartLayout。
- 采用 5 节点闭环，连接线必须边到边，不穿过文字。
- 通过该页明确展示当前四种布局无法表达循环语义时的正确降级。

### 7. 观看节奏：感知缓慢抬升

- 使用 `linear-up-step`，5 个短标题，不依赖 index。
- 线性阶梯横跨画面中下部，人物或赌场画面作为背景深度。
- 增加观看时长、停顿和声音三个微型注释，使页面不只剩一条细线。

### 8. 结论：关系先于布局

- 全幅结尾画面。
- 一句结论和四个极短关键词收束：层级、成熟度、升级、节奏。
- 不使用实现说明或验证术语。

## SmartLayout Content Rules

- 每页最多一个 smartLayout。
- `solid-pyramid` 与 `step-pyramid` 使用 4 个 cell。
- `filled-up-step` 与 `linear-up-step` 使用 5 个 cell。
- cell 标题使用平行语法，不依赖 `description` 承载关键信息。
- smartLayout 占页面约 35%–55%，与图片、观点和旁注共同构成页面。
- 所有 smartLayout 页面必须单独截图检查内部标题、色彩、方向和图片遮挡。

## Verification

创建前：

- 每页 XML 通过 `xml_text_overlap_lint.py`，`error_count == 0`。
- 所有本地图片路径可用且不重复。
- 页面计划包含 8 页，并明确四种 smartLayout 和一页循环降级。

创建后：

- `slides +xml-get` 回读 8 页。
- 回读中恰好包含四个 smartLayout，四种 `layoutType` 各一次。
- 回读中不残留 `src="@..."`。
- 获取 8/8 服务端截图并逐页目视检查。
- 必修问题：图片破损、标题裁切、文字与图片低对比、smartLayout 内部文字拥挤、连接线穿字、页面明显稀疏或重复模板化。
- 如某页仍像功能演示页，视为未完成，即使 lint 和接口均成功。

## Success Criteria

- 第一眼识别为《双峰：回归》主题电影演示，而不是 smartLayout 功能介绍。
- 每页至少有一个主视觉、一个结构层和两个辅助信息点。
- 四个 smartLayout 在复杂画面中保持可读，并分别准确表达层级、身份失真、悬疑升级和观看节奏。
- 8 页构图有明显变化，同时保持统一的色彩、字体和电影气质。
- 用户可直接从服务端截图判断视觉完成度，不依赖解释“为什么这样设计”。
