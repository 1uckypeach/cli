# Genre Router: Platform / 平台发布稿 (`route_platform`)

仅当最终交付物是小红书笔记或微信公众号文章时进入本 router；按目标平台选择且只读取一个 leaf。仅把平台作为研究对象、信息来源或业务渠道时不触发；双平台成稿分别路由和生成。

| 读者任务 / 关键词、强信号与排除 | Leaf |
|-|-|
| 形成可发布的小红书笔记；小红书、小红书写法、小红书 style、红书、XHS、小红书笔记为强信号，仅研究平台、制定运营方案或分析平台数据时不触发 | [`xiaohongshu.md`](xiaohongshu.md) |
| 形成可发布的微信公众号文章；微信公众号、公众号文章、微信长文、微信爆文为强信号，普通微信聊天、群公告、朋友圈、视频号或仅把微信作为信息来源时不触发 | [`wechat.md`](wechat.md) |
