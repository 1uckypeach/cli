# 字体系统

## 选择原则

1、语言匹配：当用户查询的是中文或者要求提供中文PPT时，需要指定中英文字体；否则只需要设置英文字体
2、选用方式：正文建议优先采用可读性强的字体，标题或特殊页面采用风格化字体加上特殊处理（全部大写、加宽字距、粗体、斜体等）来强化风格
3、字体组合必须支持整体视觉风格定位
4. 名称一致性：**确保字体名称完全相同，包括大小写和空格，以便模型可以正确使用它们**
